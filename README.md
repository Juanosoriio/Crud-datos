# CRUD datos

Este proyecto contiene ejemplos de las siguientes funcionalidades en JavaScript:

- CRUD básico
- Uso de async/await
- Callbacks
- Destructuring
- Promesas

## Estructura

- `src/Features/crud/` — Ejemplo de CRUD
- `src/Features/async-await/` — Ejemplo de async/await
- `src/Features/callbacks/` — Ejemplo de callbacks
- `src/Features/destructuring/` — Ejemplo de destructuring
- `src/Features/promises/` — Ejemplo de promesas
- `src/shared/css/` — Estilos compartidos

## Cómo usar

Abre el archivo `index.html` en la raíz para navegar por los ejemplos.
