¿Qué es Async/Await?

Async/Await es una característica de JavaScript (ES2017) que proporciona una sintaxis más limpia y legible para trabajar con Promises.

async: Se coloca antes de una función y hace que siempre retorne una Promise.

await: Solo se usa dentro de funciones async y pausa la ejecución hasta que la Promise se resuelva.

Ventajas: Código más lineal (similar al síncrono), manejo de errores con try/catch simples, y evita el "callback hell".
