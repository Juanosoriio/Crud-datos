Destructuring Objects

Aprende a extraer datos de objetos de forma elegante y concisa

¿Qué es Destructuring?

El Destructuring Assignment (desestructuración) es una expresión de JavaScript que permite unpack (sacar) valores de arrays o propiedades de objetos en variables distintas de forma rápida y elegante.

La sintaxis de desestructuración hace posible extraer múltiples propiedades de un objeto en una sola línea, evitando la repetición del nombre del objeto.

// Sintaxis básica de destructuring en objetos
const persona = { nombre: 'Juan', edad: 25 };
const { nombre, edad } = persona;
console.log(nombre); // 'Juan'
console.log(edad);   // 25

Ventajas del Destructuring:

  • Código más limpio y legible
  • Menos repetición de nombres de variables
  • Facilita el trabajo con funciones que devuelven objetos
  • Permite asignar valores por defecto
  • Renombrar variables durante la extracción

Ejemplo Práctico

Extrae datos de un objeto persona usando destructuring.

Objeto Original:
const person = {
  name: 'Juan Carlos Valencia',
  age: 30,
  city: 'Cali',
  profession: 'Desarrollador'
};

Código del Ejercicio

// Objeto con los datos de la persona
const person = {
  name: 'Juan Carlos Valencia',
  age: 30,
  city: 'Cali',
  profession: 'Desarrollador'
};

// Utilizando destructuring para extraer las propiedades
const { name, age, profession } = person;

// Imprimir los valores extraídos
console.log('Nombre:', name);
console.log('Edad:', age);
console.log('Profesión:', profession);
